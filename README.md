# KodaiBites Catering Services 🍽️

KodaiBites is a premium catering website built with React, Vite, and Tailwind CSS. We specialize in authentic South Indian cuisine, serving weddings, corporate events, and private parties all over Tamil Nadu (including Kodaikanal, Dindigul, and Theni).

## Features
- **Blazing Fast Performance**: Built with Vite and React lazy loading for instant page loads.
- **Fully Responsive**: Flawless experience on mobile, tablet, and desktop devices.
- **Modern UI**: Designed with Tailwind CSS and Framer Motion for beautiful micro-animations.
- **Advanced SEO & AEO**: Highly optimized for Search Engines and AI Answer Engines with LocalBusiness and FAQPage JSON-LD schemas, OpenGraph tags, and perfectly structured metadata.

## Setup Instructions

1. Clone the repository
2. Run `npm install` to install dependencies
3. Create a `.env` file and add your Web3Forms Access Key:
   `VITE_WEB3FORMS_ACCESS_KEY=your-access-key-here`
4. Run `npm run dev` to start the development server

## Deployment
This static website is fully optimized and ready to be deployed on platforms like **Netlify** or **Vercel**. 
Ensure your build command is set to `npm run build` and your publish directory is set to `dist`.
